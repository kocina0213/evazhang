# EVA Life Ledger

EVA 功过格：传统修身与现代成长双账本 PWA。

## Deployment

Upload the contents of `EVA_Life_Ledger_PWA_v1.1.zip/eva_pwa/` into the **repository root**, keeping `index.html`, `app.js`, `sw.js`, `manifest.webmanifest` and the `icons/` directory intact.

Then visit **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Expected URL: https://kocina0213.github.io/evazhang/

## Privacy

Do not commit personal journal entries or exported JSON backups. GitHub Pages content is public; application data stays in the device's browser storage unless exported.
